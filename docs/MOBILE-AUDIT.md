# AK Computer — મોબાઇલ ઑડિટ અને સુધારો

**તારીખ:** 2026-10-01 · **માપ:** ખરો Chromium બ્રાઉઝર, 320 / 360 / 390 / 430 / 768 / 1280px

આ કોડ વાંચીને નથી લખ્યું. **84 પાનાં ખરેખર ખોલીને માપ્યાં** — ટેબલની પહોળાઈ,
આડું ખસવું, ખાનાંની પહોળાઈ, અક્ષરનું માપ, બટનની ઊંચાઈ.

## પહેલાં શું હતું

| | |
|---|---|

| મોબાઇલમાં ખરાબ | **43** |

**43 જુદી ભૂલો નહોતી — એક જ ભૂલ 43 જગ્યાએ હતી.** સામાન્ય ટેબલને
`min-width: 550px` મળે છે, એટલે 390px ના ફોનમાં એ બેસતું નથી અને એક ખાનામાં
આડું સરકાવવું પડે. 7–9 કૉલમ હોય ત્યાં **અડધી હરોળ કદી દેખાતી જ નથી** — અને
જે ખાનું સરકે છે એવું દેખાતું નથી, એને કોઈ સરકાવતું પણ નથી.

## કઈ રીતે કર્યું — 43 ફાઇલ બદલ્યા વગર

43 ફાઇલમાં 46 ટેબલ હાથે બદલવાં એટલે **46 વાર ભૂલ થવાની તક**, અને આવતા
મહિને લખાતું 47મું ટેબલ ફરી જૂની રીતે જ લખાય.

તપાસમાં નીકળ્યું કે **એ બધાં 46 ટેબલમાં `<thead>` છે** — એટલે કાર્ડ બનાવવા
માટે જોઈતાં નામ markup માં પહેલેથી જ, ડેટાની એક હરોળ ઉપર, પડેલાં છે.

એટલે ત્રણ નિયમ, ત્રણ જગ્યાએ:

### 1 · `Tables.cards()` — `assets/app.js`

દરેક ટેબલનું `<thead>` વાંચીને એ નામ નીચેનાં ખાનાં પર ચોંટાડે, અને
`.rl-auto` વર્ગ આપે. પછી CSS કાર્ડ દોરે.

**જેને હાથ નથી લગાડતું, અને કેમ:**

- `<thead>` વગરનું ટેબલ — એ યાદી નથી, ગોઠવણ છે
- `rowlist` વગેરે જે પહેલેથી ફોન માટે બનેલાં છે — જે પાનું વિચારીને બન્યું છે એ અનુમાન કરતાં વધુ જાણે છે
- બિલ અને invoice નાં ટેબલ — ત્યાં કૉલમ **જ** દસ્તાવેજ છે
- `no-cards` વર્ગ — જાણીજોઈને બહાર નીકળવાનો રસ્તો

### 2 · `.rl-auto` — `assets/style.css`

ફોનમાં દરેક હરોળ એક કાર્ડ: **પહેલી લીટીએ નામ અને એક આંકડો**, નીચે બાકીનું
બધું પોતપોતાના નામ સાથે નાની ચિપ તરીકે, અને છેલ્લે બટન આખી પહોળાઈમાં.

**ફક્ત ફોનનો નિયમ છે.** ડેસ્કટોપનાં ટેબલ બગડેલાં નહોતાં, એટલે એમને અડ્યો
નથી. જે ચાલે છે એને ન ચાલતાના આકારમાં ઢાળવું એ સુધારો નહીં, બગાડ છે.

### 3 · `.filterbar` — ફોનમાં બે આડાં, પાંચ નહીં

`filterbar` ફિલ્ટર અને **ફોર્મ બંને** માટે વપરાય છે. "Add expense" ફોનમાં
તારીખ, શ્રેણી, રકમ, રીત અને નોંધ — પાંચેય એક 390px લીટીમાં મૂકતું. દરેક ખાનું
આશરે 70px, અને લેબલ એકબીજા પર ચડીને **"Category₹"** વંચાતું.

**એ સ્ક્રીનમાં બેસતું હતું અને વાપરી શકાતું નહોતું** — એટલે માપ પકડે નહીં,
આંખ જ પકડે.

## રંગ અને દેખાવ — આખી સાઇટમાં એક જ ભાષા

આ મહિને જે સ્ક્રીન ફરી બનાવ્યાં (ડેશબોર્ડ, વેચાણ, Settings, રોકડ-બેંક) એ
`.pane` વાપરે છે — પાતળી કિનાર, મથાળા નીચે લીટી, નરમ પડછાયો. **બાકીનાં 77
પાનાં `.card` વાપરતાં અને એમની બાજુમાં એક વર્ષ જૂનાં લાગતાં.**

`.card` ને એ જ ભાષા આપી — **એક ફેરફાર, 77 પાનાં.** બધો રંગ ટોકનથી આવે છે,
એટલે **ડાર્ક મોડ આપોઆપ સાથે ચાલે છે**, બીજી વ્યાખ્યા લખ્યા વગર.
