# AK Computer — Android એપ

દુકાનની વેબસાઈટ (shop.akdwk.in) નું મોબાઇલ રૂપ. **ઇન્ટરનેટ વગર પણ પૂરેપૂરી ચાલે છે** —
બિલ બને, ઉઘરાણી નોંધાય, આઇટમ-પાર્ટી શોધાય. નેટ આવે એટલે બધું જાતે સર્વર પર ચડી જાય.

---

## 1. ફોનમાં નાખવી (install)

એક જ વાર કરવાનું:

1. ફોનના Chrome માં ખોલો: **https://shop.akdwk.in/mobile/AKComputer-3.0.apk**
   (અથવા WhatsApp/કેબલથી `AKComputer-3.0.apk` ફાઇલ ફોનમાં મોકલો)
2. ડાઉનલોડ પૂરું થાય એટલે એના પર ટચ કરો.
3. Android પૂછશે — *"આ સ્રોતથી એપ નાખવાની મંજૂરી આપો?"* → **Settings** → **Allow from this source** ચાલુ કરો → પાછા આવો.
   (આ એટલા માટે પૂછે છે કે એપ Play Store માંથી નથી આવતી, આપણી પોતાની દુકાનની છે. જોખમ કંઈ નથી.)
4. **Install** → **Open**. હોમ સ્ક્રીન પર **AK Computer** નું આઇકન આવી જશે.

> Android 7 (2016) અને એની પછીના બધા ફોનમાં ચાલે છે.

### પહેલી વાર લોગિન

| ખાનું | શું ભરવું |
|---|---|
| Username | વેબસાઈટ પર જે વાપરો છો એ જ |
| Password | એ જ |

> સર્વરનું સરનામું હવે **પૂછતું નથી** — `shop.akdwk.in` પહેલેથી અંદર છે.
> બદલવું હોય તો લોગિન સ્ક્રીનની નીચે "Server:" પર ટચ કરો.

લોગિન વખતે **નેટ જોઈએ** (એક જ વાર). પછી બધી આઇટમ અને પાર્ટી ફોનમાં ઉતરી જાય છે —
ત્યાર બાદ નેટ ન હોય તો પણ એપ ચાલુ જ રહેશે. **ફરી લોગિન કરવું પડતું નથી.**

## 2. વાપરવી (use)

નીચે પાંચ બટન છે: **ઘર · નવું બિલ · બિલ · ઉઘરાણી · બધું**

### નેટ વગર પણ પૂરેપૂરું ચાલે એવાં કામ

| કામ | શું થાય |
|---|---|
| **નવું બિલ** | ગ્રાહક + આઇટમ શોધો, નંગ/ભાવ બદલો, **સિરિયલ નંબર** પસંદ કરો, પૈસા નોંધો, સેવ |
| **સિરિયલ નંબર** | શેલ્ફ પર પડેલા સિરિયલની યાદી બતાવે; નવો માલ હોય તો જાતે લખી શકાય. એક સિરિયલ બે જગ્યાએ ન જાય |
| **WhatsApp** | બિલ સેવ થતાં જ મોકલવાનું બટન. નેટ ન હોય તો WhatsApp પોતે પછી મોકલી દેશે |
| **બિલ** | આખી દુકાનનાં બિલ (ફક્ત આ ફોનનાં નહીં), શોધી શકાય, ત્યાંથી જ WhatsApp |
| **ઉઘરાણી** | કોના કેટલા બાકી — રકમ પ્રમાણે ગોઠવેલી યાદી |
| **પાર્ટીનો હિસાબ** | બાકી રકમ + સ્ટેટમેન્ટ, અને ત્યાં જ *પૈસા લીધા · બિલ · ઉઘરાણી યાદ · હિસાબ મોકલો* |
| **રિપોર્ટ** | આજ/7 દિવસ/આ મહિનાનું વેચાણ, આવેલા પૈસા, લેવાના-આપવાના બાકી |
| **સ્ટોક** | કઈ આઇટમ ક્યાં કેટલી, અને એના સિરિયલ નંબર |

### બાકીનું બધું — "☰ બધું"

વેબસાઈટનાં **બધાં જ સ્ક્રીન** (રિપેર, વોરંટી, ખરીદી, ચેક, હિસાબ, એકાઉન્ટિંગ,
સેટિંગ્સ… ૧૦૪ સ્ક્રીન) અહીં યાદીમાં છે, શોધી શકાય છે, અને ટચ કરતાં **એપની
અંદર જ, ફરી લોગિન કર્યા વગર** ખૂલે છે. બેક બટન દબાવો એટલે એપમાં પાછા.

* 🟢 નિશાનીવાળાં = **નેટ વગર પણ ચાલે**
* બાકીનાં = વેબસાઈટ પર ખૂલે, એટલે **નેટ જોઈએ** (એપ ચોખ્ખું કહી દે છે)

> વેબસાઈટમાં નવું સ્ક્રીન ઉમેરાય તો એ **જાતે જ** એપની યાદીમાં આવી જાય છે —
> મેનુની એક જ યાદી બંને જગ્યાએ વપરાય છે (`includes/menu.php`).

### અધૂરું બિલ ખોવાતું નથી

બિલ લખતાં લખતાં સિરિયલ જોવા બીજી સ્ક્રીન પર જાઓ, ફોન બંધ થઈ જાય, કે Android
એપ બંધ કરી નાખે — **જે લખ્યું હતું એ પાછું મળે છે**. દરેક ફેરફારે ડ્રાફ્ટ
ફોનમાં સેવ થાય છે.

### સિંક ક્યારે થાય

* એપ ખૂલે ત્યારે · નેટ પાછું આવે એ ઘડીએ · દર થોડી વારે · ⟳ દબાવો ત્યારે (તરત)

## 2b. ગ્રાહક / ડીલર માટે એ જ એપ

લોગિન સ્ક્રીન પર **"🛒 Browse products & prices"** — લોગિન વગર:

* બધી પ્રોડક્ટ, ભાવ અને **સ્ટોક છે કે નહીં** (વેબસાઈટ જેમ બતાવે એમ જ)
* કાર્ટમાં નાખો → નામ/મોબાઈલ → **ઓર્ડર** (દુકાનના Web Orders માં આવે)
* **ડીલર લોગિન** (મોબાઈલ + પાસવર્ડ) કરે તો **એનો સ્પેશિયલ ભાવ** દેખાય
* નેટ વગર પણ ભાવ જોઈ શકાય; ઓર્ડર કતારમાં રહીને પછી જાય — **બે વાર ન જાય**

એટલે **એક જ APK** — સ્ટાફ લોગિન કરે તો દુકાનનું સોફ્ટવેર, ગ્રાહક ખોલે તો દુકાન.

## 3. કંઈક ખોટું થાય તો

| શું દેખાય છે | શું થયું છે | શું કરવું |
|---|---|---|
| પીળી પટ્ટી "નેટ નથી" | નેટ નથી | કંઈ નહીં. કામ ચાલુ રાખો, બધું સચવાય છે. |
| ⏳ બિલ પર ઊભું રહે | સર્વર જવાબ નથી આપતું | ⟳ દબાવો. તોય ન જાય તો નેટ તપાસો. |
| "ફરી લોગિન કરવું પડશે" | ટોકન રદ થયું | ફરી લોગિન કરો. **કતારમાં પડેલાં બિલ ભૂંસાતાં નથી** — લોગિન પછી જાતે ચડી જશે. |
| લાલ "ધ્યાન આપો" | સર્વરે એ બિલ ના પાડી (દા.ત. આઇટમ ડિલીટ થઈ ગઈ) | સર્વરે શું કહ્યું એ ત્યાં જ લખેલું છે. વેબસાઈટ પરથી સુધારીને ફરી ⟳. |

**એક જ બિલ બે વાર નહીં ચડે.** દરેક બિલ સાથે એક ખાનગી નંબર (UUID) જાય છે; સર્વરે
એ પહેલાં જોયો હોય તો નવું બિલ ન બનાવતાં, જૂનું જ પાછું આપે છે. જવાબ રસ્તામાં
ખોવાઈ જાય અને ફોન ફરી મોકલે તો પણ ડબલ એન્ટ્રી થતી નથી.

**એપ બંધ કરી નાખો, ફોન રીસ્ટાર્ટ કરો, બેટરી ઊતરી જાય** — ન ચડેલું બિલ ફોનમાં જ
રહે છે અને પછી ચડે છે.

## 4. ફરીથી બનાવવી (build)

આ ભાગ ટેક્નિકલ છે — રોજિંદા વપરાશમાં એની જરૂર નથી.

```bash
# એક વાર જોઈએ: Android SDK + JDK 17 + Gradle 8.x
export ANDROID_HOME=/opt/android-sdk        # જ્યાં SDK હોય ત્યાં
cd mobile
gradle :app:assembleRelease
```

તૈયાર apk: `mobile/app/build/outputs/apk/release/app-release.apk`

વહેંચવા માટે એને `mobile/AKComputer-3.0.apk` તરીકે કૉપી કરીને commit કરો —
પછી એ સીધી `https://shop.akdwk.in/mobile/AKComputer-3.0.apk` પરથી ડાઉનલોડ થાય છે.

નવું વર્ઝન કાઢતી વખતે `app/build.gradle` માં `versionCode` અને `versionName`
વધારવા — નહીં તો Android જૂની એપ પર નવી નાખવા નહીં દે.

### અંદર શું છે

```
mobile/www/          ← એપ આખી અહીં છે (HTML/CSS/JS), આ જ ફાઇલો સુધારવાની
  index.html         ખોખું
  app.css            ફોન માટેની ડિઝાઇન
  db.js              ફોનનું પોતાનું ડેટાબેઝ (IndexedDB)
  sync.js            સિંક એન્જિન — શું ક્યારે ચડે/ઊતરે
  ui.js              લોગિન, ઘર, બિલ બનાવવું, સિરિયલ, બિલની યાદી
  more.js            પાર્ટીનો હિસાબ, ઉઘરાણી, રિપોર્ટ, સ્ટોક, "બધું"
mobile/app/          Android નું પડીકું (WebView એક જ Java ફાઇલમાં)
mobile/akshop.keystore  સહી કરવાની ચાવી — આ ખોવાય તો હાલની એપ પર update નહીં થાય
```

`www_assets/` જાતે બનતું ફોલ્ડર છે — gradle દર વખતે `www/` માંથી કૉપી કરે છે.
એમાં હાથે ફેરફાર ન કરવો.

### સર્વર બાજુ

એપ `api.php` સાથે વાત કરે છે:

| કૉલ | કામ |
|---|---|
| `POST ?r=login` | ટોકન લે છે (પાસવર્ડ ફોનમાં સચવાતો નથી, માત્ર ટોકન) |
| `GET ?r=sync&since=…` | આઇટમ/પાર્ટી/લોકેશન ઉતારે છે; `since` પછીનું જ આવે |
| `POST ?r=sales` | બિલ ચડાવે છે (`client_uuid` સાથે) |
| `POST ?r=payments` | ઉઘરાણી ચડાવે છે (`client_uuid` સાથે) |
| `GET ?r=menu` | વેબસાઈટના મેનુની યાદી, પરમિશન પ્રમાણે ગાળીને |
| `GET ?r=weblink&to=` | એક જ વાર ચાલે એવી લિંક, જેથી વેબસાઈટનું સ્ક્રીન ફરી લોગિન વગર ખૂલે |
| `POST ?r=whatsapp` | બિલ દુકાનના WhatsApp API થી મોકલે (એપ ફક્ત કયું બિલ એ કહે, લખાણ નહીં) |
| `POST ?r=reminder` | ઉઘરાણી યાદ — રકમ સર્વર પર ખાતાવહીમાંથી ગણાય |
| `GET ?r=catalog` | ગ્રાહક/ડીલર માટે પ્રોડક્ટ + ભાવ + સ્ટોક (લોગિન વગર, rate-limited) |
| `POST ?r=wlogin` | ડીલર લોગિન (મોબાઈલ + પાસવર્ડ) |
| `POST ?r=worder` | ઓર્ડર — દરેક લાઇનનો ભાવ સર્વર પર જ નક્કી થાય |

જરૂરી migration: **`upgrade_v70.sql`**, **`v71.sql`** અને **`v72.sql`** (`client_uuid`, `updated_at`, ટોકનનું
device/last_seen). વેબસાઈટ પર **Settings → Update** પછી **Migrate** ચલાવવું.


બે જગ્યાએ ગુજરાતી જાણી જોઈને રાખી છે, કારણ કે એ **વાંચવાનું લખાણ નથી — ટાઇપ થતા શબ્દો છે**:

1. `includes/wa_lang.php` — WhatsApp બોટની en/gu/hi ટેબલ. જે ગ્રાહકે ગુજરાતી પસંદ કરી હોય એને ગુજરાતીમાં જ જવાબ જવો જોઈએ.
2. બોટના **input pattern** — `preg_match`, `$has()`, filler-word યાદી, અને **ઓફર બંધ કરવાના શબ્દો** (`બંધ`, `બંધ કરો`). ગ્રાહક "બંધ" લખે એટલે મેસેજ બંધ થવા જ જોઈએ — એ અનુવાદ કરવો એ પરવાનગી પાછી ખેંચવાની વાત ન સાંભળવા બરાબર થાત.

એ જ કારણે `catalog.php` ના meta keywords માં ગુજરાતી શબ્દો રહ્યા છે — એ Google માં લોકો જે ટાઇપ કરે છે એ છે.
