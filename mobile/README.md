# AK Computer — Android એપ

દુકાનની વેબસાઈટ (shop.akdwk.in) નું મોબાઇલ રૂપ. **ઇન્ટરનેટ વગર પણ પૂરેપૂરી ચાલે છે** —
બિલ બને, ઉઘરાણી નોંધાય, આઇટમ-પાર્ટી શોધાય. નેટ આવે એટલે બધું જાતે સર્વર પર ચડી જાય.

---

## 1. ફોનમાં નાખવી (install)

એક જ વાર કરવાનું:

1. ફોનના Chrome માં ખોલો: **https://shop.akdwk.in/mobile/AKComputer-1.0.apk**
   (અથવા WhatsApp/કેબલથી `AKComputer-1.0.apk` ફાઇલ ફોનમાં મોકલો)
2. ડાઉનલોડ પૂરું થાય એટલે એના પર ટચ કરો.
3. Android પૂછશે — *"આ સ્રોતથી એપ નાખવાની મંજૂરી આપો?"* → **Settings** → **Allow from this source** ચાલુ કરો → પાછા આવો.
   (આ એટલા માટે પૂછે છે કે એપ Play Store માંથી નથી આવતી, આપણી પોતાની દુકાનની છે. જોખમ કંઈ નથી.)
4. **Install** → **Open**. હોમ સ્ક્રીન પર **AK Computer** નું આઇકન આવી જશે.

> Android 7 (2016) અને એની પછીના બધા ફોનમાં ચાલે છે.

### પહેલી વાર લોગિન

| ખાનું | શું ભરવું |
|---|---|
| સર્વર | `https://shop.akdwk.in` (પહેલેથી ભરેલું આવે છે) |
| યુઝરનેમ | વેબસાઈટ પર જે વાપરો છો એ જ |
| પાસવર્ડ | એ જ |

લોગિન વખતે **નેટ જોઈએ** (એક જ વાર). પછી બધી આઇટમ અને પાર્ટી ફોનમાં ઉતરી જાય છે —
ત્યાર બાદ નેટ ન હોય તો પણ એપ ચાલુ જ રહેશે. **ફરી લોગિન કરવું પડતું નથી.**

---

## 2. વાપરવી (use)

નીચે પાંચ બટન છે:

**🏠 ઘર** — આજનું વેચાણ, આજની ઉઘરાણી, કેટલા બિલ હજી સર્વર પર ચડ્યા નથી.

**🧾 નવું બિલ**
1. ગ્રાહકનું નામ લખો (જૂની પાર્ટી હોય તો ટાઇપ કરતાં જ યાદી નીચે દેખાશે — વચ્ચેનો શબ્દ લખો તો પણ મળી જશે).
2. આઇટમ શોધો → ટચ કરો → જથ્થો અને ભાવ.
3. કેટલા પૈસા મળ્યા એ લખો (બાકી ઉધાર થઈ જશે).
4. **બિલ સેવ કરો**.

બિલ પહેલાં **ફોનમાં** સેવ થાય છે, પછી સર્વર પર જાય છે. એટલે નેટ ન હોય તો પણ
બિલ ક્યારેય ખોવાતું નથી — ઉપર પીળી પટ્ટી દેખાશે "નેટ નથી — બિલ ફોનમાં સચવાયેલું છે".

**📄 બિલ** — આ ફોન પરથી બનેલાં બધાં બિલ. ⏳ = હજી ચડ્યું નથી, ✓ = ચડી ગયું (સાથે બિલ નંબર).

**₹ ઉઘરાણી** — કોના કેટલા બાકી છે એની યાદી, અને ત્યાં જ પૈસા જમા નોંધવાની સગવડ.

**⟳ સિંક** — જાતે ચડાવવા/ઉતારવા માટે. સામાન્ય રીતે એની જરૂર પડતી નથી, એપ
પોતે જ કરી લે છે.

### સિંક ક્યારે થાય

* એપ ખૂલે ત્યારે
* નેટ પાછું આવે એ જ ઘડીએ
* દર થોડી વારે, જ્યાં સુધી કતાર ખાલી ન થાય
* ⟳ બટન દબાવો ત્યારે (આ વખતે રાહ જોયા વગર તરત)

## 3. કંઈક ખોટું થાય તો

| શું દેખાય છે | શું થયું છે | શું કરવું |
|---|---|---|
| પીળી પટ્ટી "નેટ નથી" | નેટ નથી | કંઈ નહીં. કામ ચાલુ રાખો, બધું સચવાય છે. |
| ⏳ બિલ પર ઊભું રહે | સર્વર જવાબ નથી આપતું | ⟳ દબાવો. તોય ન જાય તો નેટ તપાસો. |
| "ફરી લોગિન કરવું પડશે" | ટોકન રદ થયું | ફરી લોગિન કરો. **કતારમાં પડેલાં બિલ ભૂંસાતાં નથી** — લોગિન પછી જાતે ચડી જશે. |
| લાલ "ધ્યાન આપો" | સર્વરે એ બિલ ના પાડી (દા.ત. આઇટમ ડિલીટ થઈ ગઈ) | સર્વરે શું કહ્યું એ ત્યાં જ લખેલું છે. વેબસાઈટ પરથી સુધારીને ફરી ⟳. |

**એક જ બિલ બે વાર નહીં ચડે.** દરેક બિલ સાથે એક ખાનગી નંબર (UUID) જાય છે; સર્વરે
એ પહેલાં જોયો હોય તો નવું બિલ ન બનાવતાં, જૂનું જ પાછું આપે છે. જવાબ રસ્તામાં
ખોવાઈ જાય અને ફોન ફરી મોકલે તો પણ ડબલ એન્ટ્રી થતી નથી.

**એપ બંધ કરી નાખો, ફોન રીસ્ટાર્ટ કરો, બેટરી ઊતરી જાય** — ન ચડેલું બિલ ફોનમાં જ
રહે છે અને પછી ચડે છે.

## 4. ફરીથી બનાવવી (build)

આ ભાગ ટેક્નિકલ છે — રોજિંદા વપરાશમાં એની જરૂર નથી.

```bash
# એક વાર જોઈએ: Android SDK + JDK 17 + Gradle 8.x
export ANDROID_HOME=/opt/android-sdk        # જ્યાં SDK હોય ત્યાં
cd mobile
gradle :app:assembleRelease
```

તૈયાર apk: `mobile/app/build/outputs/apk/release/app-release.apk`

વહેંચવા માટે એને `mobile/AKComputer-1.0.apk` તરીકે કૉપી કરીને commit કરો —
પછી એ સીધી `https://shop.akdwk.in/mobile/AKComputer-1.0.apk` પરથી ડાઉનલોડ થાય છે.

નવું વર્ઝન કાઢતી વખતે `app/build.gradle` માં `versionCode` અને `versionName`
વધારવા — નહીં તો Android જૂની એપ પર નવી નાખવા નહીં દે.

### અંદર શું છે

```
mobile/www/          ← એપ આખી અહીં છે (HTML/CSS/JS), આ જ ફાઇલો સુધારવાની
  index.html         ખોખું
  app.css            ફોન માટેની ડિઝાઇન
  db.js              ફોનનું પોતાનું ડેટાબેઝ (IndexedDB)
  sync.js            સિંક એન્જિન — શું ક્યારે ચડે/ઊતરે
  ui.js              બધી સ્ક્રીન
mobile/app/          Android નું પડીકું (WebView એક જ Java ફાઇલમાં)
mobile/akshop.keystore  સહી કરવાની ચાવી — આ ખોવાય તો હાલની એપ પર update નહીં થાય
```

`www_assets/` જાતે બનતું ફોલ્ડર છે — gradle દર વખતે `www/` માંથી કૉપી કરે છે.
એમાં હાથે ફેરફાર ન કરવો.

### સર્વર બાજુ

એપ `api.php` સાથે વાત કરે છે:

| કૉલ | કામ |
|---|---|
| `POST ?r=login` | ટોકન લે છે (પાસવર્ડ ફોનમાં સચવાતો નથી, માત્ર ટોકન) |
| `GET ?r=sync&since=…` | આઇટમ/પાર્ટી/લોકેશન ઉતારે છે; `since` પછીનું જ આવે |
| `POST ?r=sales` | બિલ ચડાવે છે (`client_uuid` સાથે) |
| `POST ?r=payments` | ઉઘરાણી ચડાવે છે (`client_uuid` સાથે) |

જરૂરી migration: **`install/upgrade_v70.sql`** (`client_uuid`, `updated_at`, ટોકનનું
device/last_seen). વેબસાઈટ પર **Settings → Update** પછી **Migrate** ચલાવવું.

### ટેસ્ટ

```bash
php tests/run.php        # સર્વર બાજુના નિયમો (tests/test_api.php)
```

એપની બાજુ અસલી Chromium માં ટેસ્ટ થઈ છે — લોગિન, ઑફલાઇન બિલ, જવાબ ખોવાઈ જવો,
એપ બંધ કરીને ફરી ખોલવી, ટોકન રદ થવો, સર્વરે ના પાડવી.
